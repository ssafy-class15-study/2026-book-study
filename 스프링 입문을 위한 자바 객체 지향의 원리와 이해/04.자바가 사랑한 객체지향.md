# 4. 자바가 확장한 객체지향

## 추상 메서드와 추상 클래스

<aside>
💡

추상 메서드 → 선언부는 있는데, 구현부가 없는 메서드

</aside>

- 추상 메서드를 하나라도 가지고 있는 클래스는 반드시 추상 클래스로 선언해야 한다.
- 근데 몸체가 없이 선언만 있는 메서드는 왜 필요할까

```java
public abstract class Animal {

    // 템플릿 메서드 (변하지 않는 흐름)
    public void dailyLife() {
        wakeUp();
        makeSound();   // 🔥 추상 메서드
        eat();
        sleep();
    }

    protected void wakeUp() {
        System.out.println("잠에서 깬다");
    }

    protected void eat() {
        System.out.println("먹는다");
    }

    protected void sleep() {
        System.out.println("잔다");
    }

    // 변하는 부분
    protected abstract void makeSound();
}

```

<aside>
💡

상위 클래스는 전체 흐름을 책임지고, 하위 클래스는 달라지는 부분만 구현한다.

</aside>

### 결론

- 추상 클래스란?
    - 하나 이상의 추상 메서드를 가진 클래스
    - `abstract`  키워드 사용
    - 객체 생성 불가
    - 상속을 통해서만 사용
- 추상 메서드
    - 구현부 {} 없음
    - 하위 클래스가 반드시 구현
- 목적
    - 공통 규격(틀) 제공
    - 일부 구현 + 일부 강제 구현

### 생성자

- 클래스의 인스턴스 → 객체를 만들 때마다 new 키워드를 사용
    - 소괄호는 뭘까…
    - 클래스명() 도 메서드다.
        - 반환값이 없고 클래스명과 같은 이름을 가진 메서드를 **객체를 생성하는 메서드**
        - 자바가 기본 생성자를 자동으로 만들어 주었기 때문!!
        - 필요하다면 인자로 받는 생성자도 추가 가능
            - 그렇지만 인자가 있는 생성자를 하나라도 만든다면 **자바는 기본 생성자를 만들어주지 않는다.**

## static

- 객체는 생성자가 존재하지만, 클래스는 생성자가 존재하지 않는다.
    - 그러나 클래스가 스태틱 영역에 배치될 때 실행되는 코드 블록이 있음 → static 블록
    - 그럼 static 블록에서 사용할 수 있는 속성, 메서드는 당연히 static 멤버 뿐
    
    ```java
    public class animal{
      static{
         System.out.println("hi");
      }
    }
    
    public class Main {
        public static void main(String[] args) {
           System.out.println("main start");  
            animal penguin = new animal(); // 2. 있더라도 메인 스타트 먼저 출력
            animal rat = new animal(); //3. 여러 개 생성해도 하나만 출력
                   
           }
    }
    ```
    
    - 실제로는 해당 패키지 또는 클래스가 처음 사용될 때 로딩
    - 왜 정보가 static 영역에 로딩되지 않고 해당 클래스가 처음 사용될 때 로딩될까? → 스태틱 영역도 메모리
    - **메모리는 최대한 늦게 사용을 시작하고 빨리 반환하는 것이 정석**
    - 그치만 자바는 스태틱 영역에 한번 올라가면 프로그램이 종료되기 전까지는 해당 메모리를 반환 할 수 없다.
    - 관심있으면 JUnit @BeforeClass 찾아보셈

## final

- 마지막, 최종 → **클래스, 변수, 메서드**에 사용 가능

```java
public final class 안녕 {} // 상속 불가
public final int 숫자 = 1; // 값 변경 불가

final void 숨쉬다() { .. 로직} // 오버라이딩 불가
```

- 변수의 경우 변경 불가능, 정적 상수는 선언 시에, 또는 정적 생성자에 해당하는 static 블록 내부에서 초기화가 가능. 객체 상수 선언 시에, 또는 객체 생성자 또는 인스턴스 블록에서 초기화 가능. 객체, 지역 상수 마찬가지.

## this

<aside>
💡

**객체 내부에서 객체 자신을 지칭하는 키워드**

</aside>

```java
class Penguin {
    int var = 10;
    void test() {
     int var = 20;
        System.out.println(var); //20 ->로컬 변수
        System.out.println(this.var);//10 -> 펭귄 객체의 인스턴스 변수

 }
}
public class HelloWorld {
    public static void main(String[] args) {
        Penguin Pororo = new Penguin();
        Pororo.test();
}
```

- 지역 변수와 속성의 이름이 같은 경우 → 지역 변수가 우선
- 객체 변수와 이름이 같은 지역 변수가 있는 경우 → 객체 변수 사용 시 this 사용 필요
- 정적 변수와 이름이 같은 지역 변수가 있는 경우 → 정적 변수 사용 시 클래스명을 접두사로 사용 필요
    - 접두사란
        - this, static, 접근 제어자
