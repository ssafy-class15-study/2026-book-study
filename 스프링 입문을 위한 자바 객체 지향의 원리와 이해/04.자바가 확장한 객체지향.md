# 04. 자바가 확장한 객체 지향

### abstract 키워드 - 추상 메서드와 추상 클래스

`abstract Method` 는 선언부는 있는데 구현부는 없는 메서드이다.

- 추상 메서드를 가진 클래스는 무조건 추상 클래스여야 함.
- 추상 클래스라고 무조건 추상 메서드를 가져야하는건 아님.

→ 추상 클래스는 인스턴스를 만들 수 없다. 하지만 오버라이딩은 강제할 수 있다.

### 생성자

- `new 클래스 명()` 와 같이 객체를 생성하는 생성자를 보면, 소괄호가 보이는데 이는 생성자도 메서드라는 의미이다. 생성자는 객체 생성자 메서드로 반환 값이 없고, 클래스명과 같은 이름을 가진 메서드를 의미한다.
- 기본 생성자가 없으면 컴파일러가 만들어주지만, 하나라도 생성자가 있으면 기본 생성자를 만들어주지 않는다.
- 생성자는 오버로딩이 가능하다.

### 초기화 블록

;; 여기서 필자가 갑자기 모든 패키지와 모든 클래스가 프로그램이 실행될 때 메서드 영역에 로딩된다고 했던게 구라라고 한다.

실제로는 해당 패키지나 클래스가 ‘처음’ 사용될 때 로딩되는 것이 맞다.

따라서 클래스 정보는 해당 클래스가 코드에 맨 처음 사용될 때 메서드 영역에 로딩되며, 이때 단 한번 해당 클래스의 static 블록이 실행된다. 

- 여기서 클래스가 제일 처음 사용될 때는 1) 클래스의 정적 송석을 사용할 때 2) 클래스의 정적 메서드를 사용할 때 3) 클래스의 인스턴스를 최초로 만들 때

⇒ 메모리는 최대한 늦게 사용을 시작하고 최대한 빨리 반환하는게 좋음, static 영역도 메모리의 일부이기 때문에 처음부터 모든 클래스의 정보를 올려두는게 비정상적임 

### final

final 클래스 → 상속을 허락하지 않겠다는 의미 

final 변수 → 변수를 상수화 함. (변경 불가능) 

- 정적 상수는 선언시, 정적 생성자에 해당하는 static 블록 내부에서 초기화 가능함
- 객체 상수는 선언시, 객체 생성자 또는 인스턴스 블록에서 초기화 가능
- 지역 상수는 선언시 또는 최초 한번 초기화 가능

final 메서드 → 오버라이딩을 금지 

### instance of

- 만들어진 객체가 특정 클래스의 인스턴스인지 반환해주는 연산자
- LSP(리스코프 치환 원칙)을 어기는 코드에서 자주 등장해서, 등장했다면 냄새나는 코드인지 확인이 필요함..
- 상속 관계 뿐만 아니라 인터페이스 구현 관계에서도 동일하게 적용된다.

### interface

interface는 public 추상 메서드와 public 정적 상수만 가질 수 있다.

- 알아서  public, static, final, abstac가 붙지만 필자는 이를 명시하는게 좋은 코드라고 생각한다고 한다.. 솔직히 잘 모르겠다.

### this

지역 변수와 속성(객체 변수, 정적 변수)의 이름이 같은 경우 지역 변수가 우선한다

객체 변수와 이름이 같은 지역 변수가 있는 경우 객체 변수를 사용하려면 this를 접두사로 사용해야 한다

정적 변수와 이름이 같은 지역 변수가 있는 경우 정적 변수를 사용하려면 클래스 명을 접두사로 사용한다.
